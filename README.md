## 📋 Description
Portfolio dynamique responsive présentant mon parcours, mes projets et mes compétences en développement web.

## ✨ Fonctionnalités
- Design responsive : thème vert (desktop) / rose (mobile)
- Navigation active au scroll avec IntersectionObserver
- Filtres de projets par catégorie (Web, JS, API)
- Formulaire de contact avec validation complète
- Intégration API météo (fetch + async/await)
- Menu burger animé sur mobile

## 🛠️ Technologies utilisées
- HTML5
- CSS3 (variables CSS, Flexbox, media queries)
- JavaScript vanilla (DOM, événements, fetch, async/await)
- OpenWeatherMap API
